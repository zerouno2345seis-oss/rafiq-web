# رفيق — نسخة الويب 🌱

تطبيق ويب متجاوب (هاتف / آيباد / حاسوب) لنفس قاعدة بيانات تطبيق Android «رفيق» — نفس الحسابات، نفس الدوائر، مزامنة حية.

- ملف واحد self-contained: `index.html` (بلا أي مكتبات خارجية)
- متصل بـ Supabase مباشرة (Auth + PostgREST)
- انضمام للدوائر عبر: رمز 6 أرقام / رابط / QR
- عربي RTL + وضع داكن

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو استضفه على أي خدمة ملفات ثابتة (Vercel / GitHub Pages / Netlify).

> ملاحظة: المفتاح المدمج هو `anon/publishable` (عام بطبيعته) — الحماية الفعلية من سياسات RLS في قاعدة البيانات.
